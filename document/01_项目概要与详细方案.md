## 项目背景与意义

### 问题描述

在数字经济与产业升级双轮驱动的时代，职业格局发生深刻变化：
- **技术迭代加速**：新兴职业涌现，传统职业受冲击，职业路径难以预测
- **信息碎片化**：大学生职业信息获取主要依赖网络搜索和短视频，真实性和系统性不足
- **个性化指导缺乏**：高校就业指导多为讲座和课程，难以持续跟踪个体差异
- **规划行动脱节**：学生即使有职业目标，也缺乏长期可执行的成长路径

### 目标痛点

根据社会实践调研，大学生职业规划存在五大痛点：

1. **自我认识不清晰**：缺乏系统认识自身兴趣、能力、性格、价值观，职业目标模糊
2. **职业信息获取碎片化**：岗位、行业、技能要求信息零散，缺乏真实性和系统性
3. **职业决策缺乏个性化指导**：难以做到"一人一策"的精准规划
4. **规划与行动脱节**：不清楚各阶段应提升什么能力、参加哪些实践、考取什么证书
5. **动态调整能力弱**：传统指导方式难以及时响应就业环境变化

### 项目意义

本项目构建**基于AI的大学生职业规划智能体**，旨在：
- **精准诊断**：通过多维度评估，帮助学生深入认识自我
- **科学推荐**：基于数据驱动的匹配算法，推荐最适合的职业方向
- **落地规划**：生成可执行的成长路径和阶段性行动计划
- **动态陪伴**：持续跟踪反馈，动态优化职业规划建议

### 3. 职业匹配分析模块 `/match`

**功能描述**：基于学生画像和岗位要求，进行精准匹配分析

**核心功能**：
- **多岗位搜索**
  - 从岗位库检索目标岗位
  - 支持1-5个岗位同时分析
  - 分档展示（冲/稳/保）

- **综合匹配度计算**（相对缺陷模型）
  ```typescript
  // 相对缺陷计算：惩罚高要求岗位的低分
  const dims = ['professional', 'certificate', 'innovation', 'learning', 'stress', 'communication', 'internship']
  
  const gaps = dims.map(d => {
    const studentScore = studentProfile[d] || 0
    const jobRequirement = jobDimensions[d] || 0
    const deficit = Math.max(0, jobRequirement - studentScore)
    // 相对缺陷：缺陷 / 岗位要求
    return deficit / Math.max(1, jobRequirement)
  })
  
  const avgGap = gaps.reduce((a, b) => a + b) / dims.length
  const matchScore = Math.max(0, Math.min(100, 100 * (1 - avgGap)))
  ```
  
  **优点**：
  - 低标准岗位不会虚高分数
  - 高标准岗位缺陷被充分反映
  - 分数分布更合理（不是都80%+）

- **维度详细分析**
  - 7维逐一对标
  - 优势维度识别（学生得分≥60且无缺陷）
  - 弱势维度识别（缺陷>10分）
  - 针对性建议

- **技能缺口分析**
  - 抽取岗位要求但学生缺少的技能
  - 支持模糊匹配（如"Java"包含"javascript"则忽略）
  - Top 5技能展示

- **个性化成长规划**
  - **短期（1-3个月）**：快速补足关键短板
  - **中期（3-6个月）**：综合能力全面提升
  - **长期（6-12个月）**：冲刺目标岗位
  - 每个周期配置具体行动项

**核心数据表**：
```sql
-- 岗位标准画像

  id, job_name, company, location, salary,
  dimensions (JSON), requirements (JSON),
  industry, clean_industry
}

-- 学生画像

  id, userId, dimensions (JSON), skills (JSON),
  source, createdAt, updatedAt
}
```

// 流式处理（SSE）
const response = await axios.post(difyUrl, {
  inputs: { message, conversationId },
  response_mode: 'streaming'  // 关键：Agent必须用streaming
}, { responseType: 'stream' })

response.data.on('data', (chunk) => {
  const lines = chunk.toString().split('\n')
  lines.forEach(line => {
    if (line.startsWith('data:')) {
      const json = JSON.parse(line.slice(5))
      if (json.event === 'agent_message') {
        fullAnswer += json.answer  // 累加delta
      }
    }
  })
})

## 项目优势与创新点

### 核心竞争优势

#### 1. 科学的匹配算法（相对缺陷模型）
- **问题**：传统绝对缺陷模型导致匹配度都在80%+，用户无法区分
- **解决**：采用相对缺陷模型，`(1 - 相对缺陷) * 100`
  ```
  优势：
  ✓ 低要求岗位不会虚高分（即使完全匹配也<100）
  ✓ 高要求岗位缺陷被充分反映
  ✓ 分数分布在50-95%，区分度高
  ✓ 用户易于理解和行动
  ```

#### 2. 整合的知识体系
- **10,000+真实岗位库**
  - 覆盖100+行业、50+城市
  - 包含完整的维度评分和技能要求
  - 定期更新，确保数据新鲜度

- **职业规划知识库**
  - 7维能力体系科学设计
  - 600+技能映射
  - 500+行业发展规律
  - 100+学位提升路径

#### 3. 多轮对话AI助手
- **上下文理解**：支持持续咨询，不重复解释
- **领域知识注入**：职业规划专家知识库注入提示词
- **流式传输**：SSE实时推送，不等待完整响应
- **降级方案**：Dify不可用时本地规则自动顶替

#### 4. 完整的闭环设计
```
测评 → 分析 → 推荐 → 规划 → 反馈
  ↑                            ↓
  └────────── 迭代优化 ────────┘
```
- 每个环节都有数据支撑和AI增强
- 支持多次复盘，逐步优化规划

#### 5. 可落地的成长方案
- **阶段化规划**：短/中/长期3个阶段
- **具体行动项**：不是"学习技能"，而是"完成Github项目"
- **证书路径**：针对性推荐（软考、CPA等）
- **实习机会**：基于维度缺陷推荐实习类型

#### 6. 高保真可视化设计
- **多系列雷达图**：学生vs岗位，对比直观
- **渐变填充**：美观且专业
- **实时图表**：饼图、柱图、折线图都支持
- **PDF导出**：报告完整保存

### 创新亮点汇总

| 创新点 | 描述 | 价值 |
|--------|------|------|
| **相对缺陷算法** | 不是绝对缺陷，而是相对岗位要求的缺陷 | 匹配度分布合理，50-95%，区分度高 |
| **五环闭环设计** | 测评-分析-推荐-规划-反馈形成闭环 | 用户体验完整，不是零散功能 |
| **双Agent架构** | 简历解析和对话分离 | 各自优化，降低单点故障风险 |
| **流式对话体验** | SSE推流，实时显示AI思考 | 对标ChatGPT，交互体验顶级 |
| **多维画像体系** | 7维能力+技能标签+行业数据 | 全面诊断，不是单一维度 |
| **志愿分档系统** | 冲-稳-保三档，类比高考 | 用户易理解，降低决策成本 |
| **可导出报告** | PDF包含完整分析和规划 | 可打印保存，长期参考 |
