## 🔑 核心知识点速查

### 3个最大的创新点

1. **相对缺陷匹配算法** — 解决了传统算法的分数虚高问题
   - 详见：01第7节、04第一部分、03第二部分

2. **五环闭环设计** — 从测评到规划的完整流程覆盖
   - 详见：01第5节、04第一部分

3. **AI能力的深度集成** — 两个Agent应用分离，流式传输
   - 详见：01第6节、02第9节、03第四层

### 3个最重要的技术亮点

1. **Dify Agent集成** — SSE流式、降级方案、多轮对话
   - 详见：02第4,5节、03第四层

2. **JSON列的灵活设计** — 无需ALTER TABLE扩展维度
   - 详见：03第三层数据库设计

3. **前后分离架构** — 支持多平台、易于扩展
   - 详见：03第二层、03性能优化

### 5个核心业务流程

1. 简历解析流程：文件上传 → AI解析 → 能力画像
2. 岗位搜索流程：关键词输入 → 多条件过滤 → 匹配度排序
3. AI对话流程：用户提问 → Dify处理 → SSE推流 → 实时展示
4. 志愿填报流程：偏好设置 → 分档展示 → 选岗 → 生成报告
5. 管理员操作：登录认证 → 数据统计 → 岗位CRUD
